# zawosite-v3-react

version: v3.0.0

- **Frontend**: React + Next.js 16 + Tailwind CSS v4 + shadcn/ui + Apollo Client
- **Backend**: NestJS 12 + GraphQL (Code-First) + Apollo Server
- **Database**: Prisma ORM + PostgreSQL 16
- **Langs**: TypeScript
- **Additional Tools**: Turborepo + GraphQL Code Generator + Docker

## Technologie

- [x] React
- [x] Next.js
- [x] Tailwind
- [x] shadcn/ui
- [x] NestJS
- [x] GraphQL (code-first)
- [x] Apollo Client
- [x] Prisma
- [x] PostgreSQL
- [x] GraphQL Code Generator
- [x] NestJS Passport (JWT auth)
- [x] Turborepo

## Szybki start

1. **Baza danych**: `docker compose up -d` (lub `pnpm docker:up`)
2. **Synchronizacja bazy**: `pnpm db:emit`
3. **Uruchomienie**: `pnpm run dev`
    - Frontend (Next.js): http://localhost:3000
    - Backend GraphQL Playground: http://localhost:4000/graphql
